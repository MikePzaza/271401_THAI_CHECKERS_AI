# KING FIX — ฮอสและหมากธรรมดามีความสูงเท่ากัน (V17)

**แก้โค้ดเฉพาะ `robot_io.py` ในส่วนเลือกจุดหยิบฮอสสำรองเท่านั้น**

## ข้อเท็จจริงที่ได้รับการยืนยันจากผู้ใช้
- หมากธรรมดาและตัวฮอส **ขนาดและความสูงเท่ากัน**
- ไม่ต้องตั้ง `king_pick_z` หรือ `stock_king_pick_z` เพิ่ม
- ไม่แก้ `PICK_Z` เดิม, ปั๊มสุญญากาศ, เส้นทาง `v.move_piece()`, พิกัดการหยิบวางบนกระดาน, กล้อง, กติกา หรือส่วนอื่นของ MG400
- `live_safety_config.json` เก็บแบบเดิมจาก V17 ไม่เพิ่มค่าที่ต้องสอบเทียบ

## จุดบกพร่องที่ตรวจพบในโค้ด V17

`RobotPlanner.plan` เรียก `v.pick_stock_king()` ของระบบ V4 ซึ่งในโหมด `STOCK_DYNAMIC=True`:
- ยอมรับตัวฮอสห่างจากตำแหน่งสำรองที่บันทึกไว้ได้ `STOCK_SEARCH_PX=60` พิกเซล
- ส่งพิกัด XY จาก homography ของภาพกล้องซึ่งคำนวณนอกกระดาน จึงมีโอกาสคลาดเคลื่อนจากจุดที่เก็บจริง หัวดูดอาจลงไม่ตรงกลางฮอส
- ถ้าจุดเขียวของฮอสไม่ถูกกล้องเห็น ก็จะไม่สั่งเปลี่ยนเป็นฮอสตามข้อควรระวังเดิม

โค้ดใหม่เลือก XY จาก **`stock_pos.npz` เดิม** หลังตรวจว่าภาพกล้องเห็นตัวฮอสสีส้มพร้อมจุดเขียว **ห่างจากตำแหน่งในภาพไม่เกิน `STOCK_MATCH_PX=30`** พิกเซล ถ้าไม่ตรงจะปฏิเสธการเริ่มหยิบ พร้อมแจ้งเหตุผล แทนการเสี่ยงให้แขนดูดอากาศ

ส่วน **ฮอสที่อยู่บนกระดาน** ยังคงใช้เส้นทางหยิบแบบเดียวกับหมากธรรมดาและ `PICK_Z` ค่าเดิมทุกประการ เนื่องจากขนาดเท่ากัน อาการหัวดูดไม่ยกหลังเปิดปั๊มขณะเดินฮอสบนกระดานอาจเกี่ยวกับตำแหน่งหมากจริง แรงดูด หรือสถานะคำสั่ง MG400 ซึ่ง **ไม่อาจยืนยันสาเหตุจากไฟล์โค้ดเพียงอย่างเดียว** โดยไม่ตรวจหน้างาน/บันทึกคำสั่ง ไม่ปรับ Z โดยเดา

## การทดสอบก่อนลงกับเครื่องจริง
1. วางตัวฮอสสีส้มที่จุดเก็บเดิมให้ตรงกับตำแหน่งที่บันทึกไว้ และให้กล้องเห็นจุดเขียวชัดเจน
2. เดินเกมในโหมดทดสอบจำลองก่อน เพื่อยืนยันลำดับ `piece → king_remove → king_place` และการเดินฮอสหลังเปลี่ยนตัว
3. เปิดเครื่องจริงเฉพาะเมื่อผู้ดูแลหน้างานยืนยันพื้นที่ปลอดภัยตามขั้นตอนเดิม ทดสอบครั้งละหนึ่งตา พร้อม E-stop
4. ถ้ายังเห็นว่าหัวดูดเปิดแต่แขนไม่ยก ให้จดข้อความข้อผิดพลาด `Robot error`, `RobotMode` หรือข้อความสุดท้ายที่แสดง เพื่อตรวจว่าขัดข้องที่คำสั่งยก แรงดูด หรือพิกัดต้นทาง
5. เมื่อฮอสจริงเคลื่อนออกจากตำแหน่งที่บันทึกไว้จนกล้องแจ้งว่าไม่พบฮอส ให้จัดกลับตรงจุดเดิมหรือสอบเทียบจุดเก็บด้วยวิธีเดิม **ห้ามขยายระยะค้นหาจนหยิบผิดช่อง**

**หมายเหตุ:** เกมเดิมมีกรณีเมื่อเข้าฮอสแล้วจบเกมทันที (`crown_skipped`) ที่ไม่สลับหมากเป็นฮอสซึ่งตั้งใจไว้เดิม ไม่ได้แก้ตรรกะเกมตามข้อกำชับ
