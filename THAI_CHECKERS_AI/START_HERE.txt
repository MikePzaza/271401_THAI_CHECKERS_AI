# หมากฮอสไทย 6×6 — Dashboard ใหม่ (V6)

หน้าจอโปรแกรม Desktop ใช้ Python + Tkinter เปิดจาก VS Code ได้ ไม่ใช่เว็บไซต์

## หน้าเล่นใหม่

- ด้านบน: ชื่อเกม ระดับ ADAMS และระบุว่าใช้ MG400 เครื่องจริง
- แถวบนซ้าย: ภาพกล้อง OpenCV สด (เมื่อกล้องเปิดสำเร็จ)
- แถวบนกลาง: กระดานขาว–ฟ้า 6×6 หมายเลข 1–36 ที่แสดงหมากตามกล้องเมื่ออ่านได้
- แถวบนขวา: สถานะกล้อง / MG400 / AI / Excel / สถานะเกม และปุ่มเล็ก 4 ปุ่มแบบ 2×2
- แถวล่างเต็มความกว้าง: ประวัติของคนและ AI พร้อมคอลัมน์ลำดับ ผู้เล่น จาก ไป รายละเอียด และเวลา (เวลาแสดงในโปรแกรมเมื่อรายการเข้าสู่ตาราง)

หน้าเล่นจะแสดงได้แม้ยังไม่มีกล้องหรือ MG400 พร้อม — เพื่อดูหน้าจอและแก้การติดตั้งได้ **แต่จะยังไม่ส่งคำสั่งเคลื่อนที่ให้ MG400** ถ้าไม่ผ่านเงื่อนไขการสอบเทียบและความปลอดภัย

## รันใน VS Code / Windows

1. แตกไฟล์ ZIP แล้วเปิดโฟลเดอร์ `THAI_CHECKERS_6x6_DASHBOARD_V6` ใน VS Code
2. เปิด Terminal ภายในโฟลเดอร์นี้
3. รัน `py -3 -m pip install -r requirements.txt`
4. รัน `py -3 main.py`
5. เลือกระดับความยากแล้วกด **เริ่มเกม**

หากยังไม่มีกล้อง หน้ากล้องจะแสดง **รอภาพจากกล้อง** ส่วนกระดานขวาจะแสดงสถานะเกมเริ่มต้นพร้อมข้อความ **ยังไม่มีข้อมูลจากกล้อง** โดยไม่ถือว่าเชื่อมอุปกรณ์สำเร็จ

หากกล้องเปิดได้แต่ไม่มี `board.npz` การวาดหมากจากกล้องอาจใช้ค่าแผนที่กระดานสำรองและ **ไม่รับรองความแม่นยำในการจับคู่ช่อง** การเล่นจริงต้องสร้าง `board.npz` จากโหมด `boardcal` ของโปรแกรม V2 และทดสอบกล้องกับกระดานจริงก่อน

## โค้ดที่รักษาไว้จากเครื่องที่ใช้งานได้จริง

ไฟล์ `mg400_visionV2.py`, `calib.npz`, `clear_pos.npz` อยู่ในโปรเจกต์เหมือนเดิม **โดยไม่มีการแก้ไขเนื้อหา** ทั้งสามไฟล์เป็นชุดที่ผู้ใช้ยืนยันว่าเคยทดสอบใช้กับ MG400 จริงแล้ว แต่ **การเชื่อมกับ AI/เกมในโปรเจกต์รวมยังไม่ได้ยืนยันด้วยการทดสอบ MG400 จริง**

ระบบใช้ MG400 เครื่องจริงเท่านั้น ไม่มีตัวเลือก simulation ในหน้าเกม แต่เมื่ออุปกรณ์/ระบบความปลอดภัยไม่พร้อม โปรแกรมคงหน้าแสดงสถานะเพื่อดูได้ โดยไม่ส่งคำสั่งไปยังหุ่นยนต์

**คำเตือน:** ไม่ให้รัน `mg400_visionV2.py` เปล่า ๆ โดยไม่ระบุโหมดที่ตั้งใจ เพราะโค้ดเดิมมี `ALLOW_MOVE=True` และโหมดเริ่มต้นเป็น `play` ซึ่งอาจสั่งหุ่นยนต์เคลื่อนจริง การควบคุม MG400 ต้องมีการทดสอบ E-stop อิสระ ระบบป้องกันผู้ปฏิบัติงาน เซนเซอร์สุญญากาศ การรับรองพิกัดและเส้นทาง รวมถึงตรวจสอบ `live_safety_config.json` โดยผู้ดูแลก่อนส่งคำสั่งจริง กล้องแยกสีหมากไม่ใช่อุปกรณ์นิรภัย
